# Reporting a vulnerability

Use the repository's Security tab to report a vulnerability privately to the
maintainer. If private reporting is unavailable, open an issue asking for a
private reporting channel. Keep exploit details and sensitive data private.

For a restore or redaction bug, use a disposable workspace with synthetic
values. Include the ColdRewind version, operating system, filesystem, and
commands needed to reproduce the problem. Share raw snapshots, databases,
and command output only after reviewing their contents.
